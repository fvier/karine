## ⚡ Como Executar a Aplicação Localmente

```bash
# 1. Clonar o repositório
git clone git@github.com:fvier/karine.git
cd Karine

# 2. Ativar ambiente virtual
source venv/bin/activate

# 3. Executar o servidor de desenvolvimento
python3 run.py
```

Acesse no navegador em `http://localhost:5000` (ou `http://<seu-ip-local>:5000` para dispositivos na mesma rede local).
